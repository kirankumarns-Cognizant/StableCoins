## Selected POC

Cross-Border B2B Supplier Payment +
Stablecoin Settlement +
Treasury Liquidity +
Optional Visa Payout

## Reason

This scenario demonstrates simultaneously:

- business value
- treasury impact
- blockchain settlement
- payments architecture
- ledger
- reconciliation
- real on-chain transaction
- Visa integration opportunity

It provides a Financial Services story rather than merely demonstrating
wallet-to-wallet cryptocurrency movement.
